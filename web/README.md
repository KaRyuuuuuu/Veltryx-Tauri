# Tauri + React + Typescript

This template should help get you started developing with Tauri, React and Typescript in Vite.

## Configuration X2 et RIS

Au premier lancement de Veltryx Control, le backend cree ce fichier local :

```text
%APPDATA%\veltryx\veltryx.env
```

Il contient l'adresse X2, les identifiants X2 et l'adresse RIS. Modifie les valeurs puis redemarre Veltryx pour les appliquer. Les mises a jour de l'application ne remplacent pas ce fichier.
